## Razor if

```cs
@if(condition){
  //C#/html code here
}
```

## Razor if...else

```cs
@if(condition){
  //C#/html code here
}
else{
  //C#/html code here
}
```

## Switch

```cs
@switch(variable){
  case value1:
    //C#/html code here;
    break;
  case value2:
    //C#/html code here;
    break;
  case value3:
    //C#/html code here;
    break;
  default:
    //C#/html code here;
    break;
}
```

## Razor - foreach

```cs
@foreach(var variable in collection){
  // C#/html code here
}
```

## Razor - for

```cs
@for(initialization; condition; iteration)
{
  // C#/html code here
}
```

## Razor - Literal

```cs
@{
  @: static text
}

or
<text>static text</text>
```

## Razor - Local Function

```cs
@{
  ReturnType MethodName(arguments){
    // C#/html code here
  }
}
```
