## Razor Code Block

- Razor code block is a C# code block that contains one or more lines of C# code that contains one or more lines of C# code that can contain any statements and local functions.
  ```cs
  @{
    // C#/html code here
  }
  ```

## Razor Expression

- Razor expression is a C# expression (accessing a field, property or method call) that returns a value.
  ```cs
  @Expression
  or
  @(Expression)
  ```
